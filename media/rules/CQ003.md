# CQ003 — Function is too long

This function has more lines of code than the limit.

## Why it matters

Long functions usually do several jobs at once. They are harder to name, test, and reuse, and changes in one part affect the others.

## How to fix

- Find the separate steps (often marked by blank lines or comments) and extract each into a function.
- Name each extracted function after what it does, not how.

## Configuration

Default limit: `50`. Change it with `kasauti.thresholds.functionLength`.

## Scope

Applies to languages with a parser.
