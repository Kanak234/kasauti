# CQ005 — Control flow is nested too deeply

if/for/while/switch/try are nested deeper than the limit.

## Why it matters

Every nesting level multiplies the conditions a reader must track. Deep nesting is the most common cause of "arrow-shaped" code that nobody wants to touch.

## How to fix

- Invert conditions and return early.
- Extract the innermost block into its own function.
- Replace nested loops with a helper that processes one item.

## Configuration

Default limit: `3`. Change it with `kasauti.thresholds.nesting`.

## Scope

Applies to all languages.
