# CQ006 — File is too long

This file has more lines than the limit.

## Why it matters

Very long files usually hold several unrelated responsibilities, which leads to merge conflicts and makes code hard to find.

## How to fix

- Group related functions/classes and move each group into its own file or module.

## Configuration

Default limit: `1000`. Change it with `kasauti.thresholds.fileLength`.

## Scope

Applies to all languages.
