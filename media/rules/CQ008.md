# CQ008 — Low maintainability index

Size, complexity, and vocabulary together make this function hard to maintain.

## Why it matters

The Maintainability Index combines Halstead volume, cyclomatic complexity, and lines of code. Visual Studio treats values below 20 as a warning and below 10 as a problem.

## How to fix

- Reduce complexity first (see CQ001/CQ002).
- Shorten the function by extracting helpers.

## Configuration

Default limit: `20`. Change it with `kasauti.thresholds.maintainabilityWarning`.

## Scope

Applies to languages with a parser.
