# CQ009 — Class has too many methods

This class defines more methods than the limit.

## Why it matters

A class with very many methods usually has more than one responsibility (a "god class"), which makes it fragile and hard to test.

## How to fix

- Identify groups of methods that use the same fields and move each group into its own class.

## Configuration

Default limit: `35`. Change it with `kasauti.thresholds.classMethods`.

## Scope

Applies to languages with a parser.
