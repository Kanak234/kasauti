# CQ010 — Line is too long

This line is longer than the limit.

## Why it matters

Long lines force horizontal scrolling and hide logic off-screen, especially in side-by-side reviews.

## How to fix

- Break long expressions across lines.
- Introduce intermediate variables with descriptive names.

## Configuration

Default limit: `120`. Change it with `kasauti.thresholds.lineLength`.

## Scope

Applies to all languages.
