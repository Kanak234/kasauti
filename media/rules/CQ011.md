# CQ011 — TODO / FIXME left in code

A TODO, FIXME, HACK, or XXX marker is present.

## Why it matters

Markers are useful reminders, but forgotten ones hide known problems. This finding is informational and adds no debt.

## How to fix

- Resolve the item, or move it to your issue tracker and delete the marker.

## Configuration

This rule has no threshold; it is informational.

## Scope

Applies to all languages.
