# CQ012 — File contains syntax errors

The parser found syntax errors; results may be incomplete.

## Why it matters

Metrics are computed from the parts of the file that parse. Fix the syntax errors to get complete results.

## How to fix

- Check the editor's Problems panel for the language's own error messages.

## Configuration

This rule has no threshold; it is informational.

## Scope

Applies to languages with a parser.
