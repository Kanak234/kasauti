# KP102 — Membership test on a list inside a loop

`x in some_list` inside a loop scans the whole list every iteration.

**Category:** Performance · **Languages:** Python

## Why it matters

`in` on a list is a linear search (O(n)). Inside a loop of n iterations that is O(n²) total. On a set or dict the same `in` is O(1) on average.

## How to fix

- Convert the list to a set once, before the loop: `seen = set(items)`.
- If you also need order, keep the list and add a parallel set for lookups.

## Before → after

```
seen = []
for x in data:
    if x not in seen:
        seen.append(x)
```

```
seen = set()
for x in data:
    if x not in seen:
        seen.add(x)
```
