# KP103 — Linear search or shift inside a loop

A call that scans or shifts the whole collection runs on every iteration.

**Category:** Performance · **Languages:** Python, JavaScript, TypeScript, Java

## Why it matters

list.index / list.remove / list.pop(0) / insert(0, …) (Python), indexOf / includes / find / splice / shift (JS), List.contains / indexOf / remove(0) (Java) all walk or move every element. Calling one inside a loop turns an O(n) job into O(n²).

## How to fix

- Look-ups: build a set or dict (Map/HashMap) before the loop.
- Queue behaviour (pop(0), shift): use collections.deque / ArrayDeque.
- Removing many items: build a new filtered collection in one pass.

## Before → after

```
while queue:
    item = queue.pop(0)      # O(n) each
```

```
from collections import deque
queue = deque(queue)
while queue:
    item = queue.popleft()   # O(1)
```
