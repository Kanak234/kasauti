# KP104 — String built with += inside a loop

Strings are immutable; each += copies everything built so far.

**Category:** Performance · **Languages:** Python, Java

## Why it matters

Appending to a string in a loop copies the growing string each time: O(n²) characters copied in total. Java always pays this; CPython sometimes optimises it in place, but not reliably (not on PyPy, not when another reference exists).

## How to fix

- Python: collect pieces in a list and `"".join(parts)` once at the end.
- Java: use a StringBuilder and call toString() once.

## Before → after

```
out = ""
for w in words:
    out += w + " "
```

```
out = " ".join(words)
```
