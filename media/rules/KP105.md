# KP105 — Recursion that may be exponential

The function calls itself more than once per call and caches nothing.

**Category:** Performance · **Languages:** Python, JavaScript, TypeScript, Java

## Why it matters

Two self-calls per level (like naive Fibonacci) build a call tree that doubles at every level: O(2ⁿ). n = 40 already means about a billion calls. Memoization or a bottom-up loop makes the same algorithm O(n).

## How to fix

- Python: decorate with @functools.lru_cache(maxsize=None) (or @cache).
- Any language: keep a dict/Map of results already computed.
- Or rewrite bottom-up with a loop and two variables.

## Before → after

```
def fib(n):
    if n < 2: return n
    return fib(n-1) + fib(n-2)
```

```
from functools import cache
@cache
def fib(n):
    if n < 2: return n
    return fib(n-1) + fib(n-2)
```
