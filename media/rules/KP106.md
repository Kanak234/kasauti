# KP106 — Sorting inside a loop

A full sort runs on every iteration.

**Category:** Performance · **Languages:** Python, JavaScript, TypeScript, Java

## Why it matters

One sort is O(n log n); repeated n times it is O(n² log n). Usually the data only needs sorting once, or a heap (priority queue) gives the smallest/largest item in O(log n).

## How to fix

- Sort once before the loop.
- Need the current minimum/maximum repeatedly? Use heapq (Python) or PriorityQueue (Java).
