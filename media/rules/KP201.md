# KP201 — Dynamic code execution (eval / exec / new Function)

A string is executed as code.

**Category:** Security · **Languages:** Python, JavaScript, TypeScript

## Why it matters

If any part of that string comes from a user, a file or the network, an attacker can run arbitrary code with your program's permissions (CWE-95). AI assistants use eval as a shortcut for parsing.

## How to fix

- Parsing data? Use json.loads / JSON.parse or ast.literal_eval.
- Choosing a function by name? Use a dict of allowed functions.

## Before → after

```
value = eval(user_input)
```

```
import ast
value = ast.literal_eval(user_input)  # literals only
```
