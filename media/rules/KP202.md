# KP202 — OS command injection risk

A shell command is run, possibly built from variable data.

**Category:** Security · **Languages:** Python, JavaScript, TypeScript, Java

## Why it matters

With shell=True, os.system, child_process.exec or Runtime.exec("…" + x), characters like ; | && in the data start new commands (CWE-78). It is critical when the command text is not a fixed literal.

## How to fix

- Pass arguments as a list with shell=False: subprocess.run(["ls", path]).
- Node: use execFile/spawn with an argument array.
- Never build a command by concatenating user input.

## Before → after

```
os.system("ping " + host)
```

```
subprocess.run(["ping", "-c", "1", host], check=True)
```
