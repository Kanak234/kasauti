# KP203 — SQL built from strings (SQL injection)

A query passed to execute/query is built with f-strings, +, % or format.

**Category:** Security · **Languages:** Python, JavaScript, TypeScript, Java

## Why it matters

Inserting values into SQL text lets input like ' OR 1=1 -- change the query (CWE-89). It is the most common injection bug in generated CRUD code.

## How to fix

- Use parameters: cur.execute("SELECT * FROM u WHERE id = %s", (uid,)).
- Java: PreparedStatement with ? placeholders and setX().
- Node: db.query("… WHERE id = $1", [id]).

## Before → after

```
cur.execute(f"SELECT * FROM users WHERE name = '{name}'")
```

```
cur.execute("SELECT * FROM users WHERE name = %s", (name,))
```
