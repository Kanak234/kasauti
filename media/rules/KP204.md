# KP204 — Hard-coded secret

An API key, token, password or private key is written in the source.

**Category:** Security · **Languages:** Every language

## Why it matters

Anything in source ends up in git history, screenshots and every copy of the repo. Bots scan public GitHub for keys within minutes. AI code often pastes a key "just to make it work".

## How to fix

- Move it to an environment variable or a .env file that is in .gitignore.
- Rotate (revoke and re-create) the key — assume it is already leaked.

## Turning it off

Suppress one line with a `kasauti-disable-next-line KP204` comment, or hide every audit rule with `kasauti.audit.enabled: false`.
