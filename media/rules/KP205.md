# KP205 — Unsafe deserialization

pickle / marshal / yaml.load / ObjectInputStream / unserialize can execute code while loading.

**Category:** Security · **Languages:** Python, JavaScript, TypeScript, Java

## Why it matters

These formats can describe objects whose construction runs code. Loading a file or message an attacker controls is remote code execution (CWE-502).

## How to fix

- Use JSON for data exchange.
- YAML: yaml.safe_load.
- If you must unpickle, only load files you created yourself and verify an HMAC first.

## Turning it off

Suppress one line with a `kasauti-disable-next-line KP205` comment, or hide every audit rule with `kasauti.audit.enabled: false`.
