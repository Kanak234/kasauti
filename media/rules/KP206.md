# KP206 — TLS certificate verification disabled

HTTPS is used without checking the server certificate.

**Category:** Security · **Languages:** Python, JavaScript, TypeScript, Java

## Why it matters

verify=False / rejectUnauthorized: false accepts any certificate, so anyone on the network path can read and change the traffic (CWE-295). Generated code adds it to "fix" a certificate error.

## How to fix

- Remove the flag and fix the real cause (install the CA, use certifi).
- For a self-signed internal server, pass its CA file explicitly.

## Turning it off

Suppress one line with a `kasauti-disable-next-line KP206` comment, or hide every audit rule with `kasauti.audit.enabled: false`.
