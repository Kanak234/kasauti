# KP207 — Weak hash algorithm (MD5 / SHA-1)

MD5 or SHA-1 is used.

**Category:** Security · **Languages:** Python, JavaScript, TypeScript, Java

## Why it matters

Both have practical collision attacks. Fine as a non-security checksum, never for passwords, signatures or integrity against an attacker (CWE-328).

## How to fix

- Integrity: SHA-256 or better.
- Passwords: bcrypt, scrypt or Argon2 — never a plain hash.
