# KP208 — HTML injection sink (XSS)

Non-literal data is written as HTML (innerHTML, document.write, dangerouslySetInnerHTML).

**Category:** Security · **Languages:** JavaScript, TypeScript

## Why it matters

If the data contains <script> or an onerror= attribute it runs in the user's browser (CWE-79).

## How to fix

- Use textContent for text.
- Build elements with createElement, or sanitise with DOMPurify first.

## Turning it off

Suppress one line with a `kasauti-disable-next-line KP208` comment, or hide every audit rule with `kasauti.audit.enabled: false`.
