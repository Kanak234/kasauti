# KP301 — Import not declared in the project's dependencies

A third-party package is imported but is not in requirements/pyproject/package.json.

**Category:** AI-risk · **Languages:** Python, JavaScript, TypeScript

## Why it matters

Either the project will crash on a fresh install, or the package name was invented by an AI. Researchers found about a fifth of AI-recommended packages do not exist, and attackers register those names with malware ("slopsquatting").

## How to fix

- Check the exact name on pypi.org / npmjs.com before installing.
- Add the verified package to your manifest.
- Turn on kasauti.audit.checkRegistry to verify names automatically.

## Turning it off

Suppress one line with a `kasauti-disable-next-line KP301` comment, or hide every audit rule with `kasauti.audit.enabled: false`.
