# KP302 — Package does not exist on the registry

The imported name is not on PyPI / npm — likely hallucinated.

**Category:** AI-risk · **Languages:** Python, JavaScript, TypeScript

## Why it matters

Code that imports a non-existent package is an open invitation: anyone can publish that name tomorrow and it will be installed by everyone who runs `pip install` / `npm install` for this code.

## How to fix

- Do not create or install a package with this name.
- Find the real library that does the job and import that instead.

## Turning it off

Suppress one line with a `kasauti-disable-next-line KP302` comment, or hide every audit rule with `kasauti.audit.enabled: false`.
