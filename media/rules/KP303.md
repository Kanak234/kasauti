# KP303 — Package is brand-new on the registry

The package was first published less than 90 days ago.

**Category:** AI-risk · **Languages:** Python, JavaScript, TypeScript

## Why it matters

Very new packages with names an AI suggested are the typical shape of a slopsquatting attack. It may be fine — but it deserves a manual look before it gets access to your machine.

## How to fix

- Open the package page: check the author, repository link, download count and source.
- Prefer an established library if one exists.

## Turning it off

Suppress one line with a `kasauti-disable-next-line KP303` comment, or hide every audit rule with `kasauti.audit.enabled: false`.
