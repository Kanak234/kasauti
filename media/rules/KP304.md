# KP304 — Exception swallowed

A bare `except:` or an empty catch block hides errors.

**Category:** AI-risk · **Languages:** Python, JavaScript, TypeScript, Java

## Why it matters

Generated code often wraps everything in try/except: pass so the demo "works". The bug is still there — it just fails silently later with wrong data. A bare except also catches Ctrl+C and sys.exit.

## How to fix

- Catch the specific exception you expect.
- At minimum log it; usually re-raise or return an error.

## Before → after

```
try:
    data = load()
except:
    pass
```

```
try:
    data = load()
except FileNotFoundError as e:
    log.warning("no data file: %s", e)
    data = {}
```
