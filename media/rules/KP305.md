# KP305 — Placeholder or stub left in code

A function body is only pass / ... / NotImplementedError, or a comment says "your code here".

**Category:** AI-risk · **Languages:** Python, JavaScript, TypeScript, Java

## Why it matters

Assistants leave placeholders like "# ... rest of the code" or "implement this". The program compiles, so nobody notices the missing logic until it is used.

## How to fix

- Implement the missing part or delete the stub.
- Abstract methods: mark them with @abstractmethod and they are ignored.

## Turning it off

Suppress one line with a `kasauti-disable-next-line KP305` comment, or hide every audit rule with `kasauti.audit.enabled: false`.
