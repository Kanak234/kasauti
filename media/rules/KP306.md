# KP306 — Unreachable code

Statements follow a return / raise / throw / break / continue in the same block.

**Category:** AI-risk · **Languages:** Python, JavaScript, TypeScript, Java

## Why it matters

Code that can never run usually means the logic is not what the author thought — often a merge of two AI suggestions.

## How to fix

- Delete it, or move it before the jump if it was meant to run.

## Turning it off

Suppress one line with a `kasauti-disable-next-line KP306` comment, or hide every audit rule with `kasauti.audit.enabled: false`.
