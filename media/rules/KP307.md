# KP307 — Mutable default argument

A list, dict or set is used as a default parameter value.

**Category:** AI-risk · **Languages:** Python

## Why it matters

The default is created once, when the function is defined, and shared by every call. Items added in one call appear in the next — a classic, silent bug.

## How to fix

- Use None as the default and create the object inside the function.

## Before → after

```
def add(x, items=[]):
    items.append(x)
    return items
```

```
def add(x, items=None):
    if items is None:
        items = []
    items.append(x)
    return items
```
