# KP401 — if/else that only returns a boolean

The branches return true and false — return the condition itself.

**Category:** Simplify · **Languages:** Python, JavaScript, TypeScript, Java

## Why it matters

Four lines that say "if this is true, return true" are one expression. Shorter code with the same behaviour is easier to read and review.

## How to fix

- Return the condition (wrapped in bool() if it is not already a boolean in Python).

## Before → after

```
if age >= 18:
    return True
else:
    return False
```

```
return age >= 18
```
