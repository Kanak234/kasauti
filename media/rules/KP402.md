# KP402 — Comparison with a boolean literal

`x == True` / `x === false` instead of using the value directly.

**Category:** Simplify · **Languages:** Python, JavaScript, TypeScript, Java

## Why it matters

The comparison adds nothing for real booleans and behaves surprisingly for non-booleans (1 == True is true in Python).

## How to fix

- Write `if x:` / `if not x:` (or `if (x)` / `if (!x)`).

## Turning it off

Suppress one line with a `kasauti-disable-next-line KP402` comment, or hide every audit rule with `kasauti.audit.enabled: false`.
