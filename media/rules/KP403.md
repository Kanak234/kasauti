# KP403 — range(len(x)) loop

Index loop where enumerate (or direct iteration) is clearer.

**Category:** Simplify · **Languages:** Python

## Why it matters

for i in range(len(xs)) followed by xs[i] is the C habit. Python gives you the item (and the index, if needed) directly; it is shorter and avoids off-by-one bugs.

## How to fix

- Need the item only: for x in xs.
- Need both: for i, x in enumerate(xs).

## Before → after

```
for i in range(len(names)):
    print(i, names[i])
```

```
for i, name in enumerate(names):
    print(i, name)
```
