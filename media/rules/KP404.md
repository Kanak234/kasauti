# KP404 — Manual sum loop

A loop that only adds each item to a total.

**Category:** Simplify · **Languages:** Python, JavaScript, TypeScript

## Why it matters

sum() (or reduce) says the intent in one line and runs in optimised C in Python.

## How to fix

- Python: total = sum(xs).
- JS: const total = xs.reduce((a, b) => a + b, 0).

## Before → after

```
total = 0
for x in prices:
    total += x
```

```
total = sum(prices)
```
