# KP405 — Non-idiomatic None / emptiness check

`== None` or `len(x) == 0` instead of `is None` / `not x`.

**Category:** Simplify · **Languages:** Python

## Why it matters

`== None` can be fooled by a custom __eq__; `is None` cannot. `len(x) == 0` is longer than `not x` and fails on iterables without len.

## How to fix

- Use `x is None` / `x is not None`.
- Use `if not items:` for "is empty".
